# Preprocesamiento - Ciencia de Datos

## Nombre del Proyecto
**preprocesamiento-cienciadatos**

## Objetivo
Aplicar de manera práctica el uso de Git y GitHub para la gestión de versiones y la colaboración en proyectos de Ciencia de Datos. Implementar un preprocesamiento completo de datasets usando Pandas, incluyendo:

- Gestión de valores nulos
- Normalización de datos numéricos
- Codificación de variables categóricas
- Eliminación de duplicados

## Estructura de Carpetas

```
preprocesamiento-cienciadatos/
│
├── README.md                   # Descripción general del proyecto
├── .gitignore                  # Archivos y carpetas ignorados por Git
├── DOCUMENTACION.md            # Documentación técnica del proyecto
│
├── data/
│   ├── raw/                    # Datos originales sin procesar
│   └── processed/              # Datos procesados y listos para análisis
│
├── scripts/
│   └── preprocesamiento.py     # Script principal de preprocesamiento
│
└── .github/
    └── workflows/
        └── ci.yml              # Workflow de GitHub Actions (CI)
```

## Tecnologías Utilizadas
- Python 3.x
- Pandas
- Scikit-learn
- Git & GitHub
- GitHub Actions
